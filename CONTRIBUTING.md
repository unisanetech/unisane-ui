# Contributing

Contributions are accepted under the repository's MIT License. By submitting a
contribution, you confirm that you have the right to provide it under that license and
that it does not contain confidential information, credentials, customer data, or code
whose license is incompatible with this repository.

Use the repository's documented package boundaries, add focused behavior proof, and do
not introduce deprecated aliases, sibling-source dependencies, or generated-file edits.
Do not include credentials, private customer information, or exploit details in public
issue reports.
