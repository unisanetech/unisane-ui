# Communication Mail Email Template System References

## Changelog

- `2026-05-28`: Added the asset README for email design-system visual references and clarified that the images are inspiration targets, not exact templates to copy.

## Purpose

This folder stores visual references for the draft communication, mail, and email template system plan.

These images are design-pattern references only. They are not canonical Unisane templates, not implementation specs, and not instructions to copy the exact pixels, copy, branding, UI chrome, or layout from the screenshots.

Use them to discuss the quality bar for:

1. polished email composition
2. clear visual hierarchy
3. responsive desktop and mobile behavior
4. branded headers and logos
5. strong call-to-action treatment
6. security, OTP, billing, welcome, and onboarding patterns
7. readable tables and key-value rows
8. thoughtful spacing, typography, and media usage
9. preview-gallery presentation with desktop and mobile frames

## Usage Rule

When these references are used in implementation planning, extract reusable patterns into the email design system:

1. template layout variants
2. typography roles
3. media roles
4. button treatments
5. status badges
6. OTP blocks
7. key-value tables
8. responsive preview states

Do not hard-code one-off designs from these images into platform apps or core modules.
